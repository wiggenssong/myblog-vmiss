# VuePress 与 Plume 主题初体验

## 为什么选 VuePress

- Markdown 写作，专注内容
- Vue 生态，扩展能力强
- 静态构建，部署简单

## Plume 主题亮点

- 分类 / 标签 / 归档 开箱即用
- 内置全文搜索
- 暗色模式自适应
- 移动端响应式

## 开始使用

```bash
npm create vuepress-theme-plume@latest
```
